# Simone GM Panel Sounds

Soundboard, playlists, groups, and positional audio for Simone GM Panel.

## Requirements

- Simone GM Panel Core (`simone-gm-panel`) 1.0.0 or newer.

## Features

- Soundboard and saved playlists.
- Grouped, token-bound, and positional playback.
- Owned AmbientSound lifecycle with cleanup and migration safeguards.
- Uses Core's live selected-token and canvas-focus services for token audio and session icons.

## Installation

Install from the Foundry VTT **Add-on Modules** screen using the manifest URL from the latest GitHub release.

## Compatibility

- Foundry Virtual Tabletop 14
- Version: 1.0.0

## Support

Report reproducible issues through this repository's GitHub Issues page. Include the Foundry version, active system version, enabled GM Panel packages, and relevant console errors.
